# PriorityDMs

Basically lets you get notifications from certain people you whitelist while on DND (Do Not Disturb)

Maintainer: **s4ge.lol** (`1072867100957347840`).

Open the plugin settings, search your friends by name, username, or nickname, and select **+ Allow**. The **Allowed** tab lets you review and remove people. You can also right-click a user and choose **Allow DMs during DND**.

Use **Test notification** to check your setup. Desktop notifications require permission and may still be suppressed by OS Focus settings. Discord must be running with the plugin enabled; mobile push notifications are unchanged.

## How to install a plugin

1. Direct your terminal to the `userplugins` folder, e.g. `cd src/userplugins`.
2. Copy a GitHub repo link — `https://github.com/s4gelol/priorityDms`.
3. Inside your terminal, run this
```sh
git clone https://github.com/CatLocky/priorityDms
```
